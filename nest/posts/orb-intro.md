开场那颗球，不是我的代码。

它原本是一个独立网页，最外层是一块 `canvas`，里面跑着一段很长的 WGSL：每帧在 GPU 上算出一层玻璃液体的折射和流动。我第一次把它打开的时候，坐在椅子上看了一分多钟——那种「东西在玻璃里游」的感觉，不是 CSS 动画能装出来的。

我想把它放进小窝，但有一个前提：**不碰它**。参数一个都不动，脚本一个字都不改。任何一次「顺手优化」，都可能毁掉原作者调了很久的手感。

做法其实很土：把整个页面原封不动放进一个 `iframe`，让它铺满整屏，盖在主页上面。

```
<div class="intro" id="intro">
  <iframe id="introFrame" src="assets/orb/splash.html"></iframe>
  <button id="introTap"></button>
  <div class="intro__hint">点一下 · 进小窝</div>
</div>
```

这里有几个必须处理的细节，漏一个就会出问题：

- `iframe` 设成 `pointer-events:none`，否则它会把点击吃掉，用户怎么点都没反应；
- 在上面盖一个整屏的 `button`，负责接住点击、回车、空格和 Esc；
- 退出时先加淡出类，等 950 毫秒过渡结束，再把整个节点从 DOM 里摘掉，不然它一直压在页面上，滚动会被卡住；
- 用 `?enter=1` 或者带 `#home` 之类的锚点进来时，直接跳过开场，方便调试和分享。

那颗球依赖 `navigator.gpu`。浏览器不支持、或者显卡驱动被拉黑的时候，页面会自动进入一个降级状态，换上一颗静态的玻璃球——不白屏，也不报错。

最后是那个我最在意的步骤：怎么证明我真的没改它。

我把线上原版的 `<script type="module">` 整段抠出来，和改完之后的一起算哈希：

```
whole file identical: True
script identical: True
96214 字节 · 86692 字符 · sha f2cb8d61c9c5eaa9
```

两个哈希一模一样。那一刻才敢说「参数一个没动」不是口号，是可以被验证的。

后来陆续加过按钮、加过背景、改过文案，但这段脚本的哈希到今天还是那一个。
